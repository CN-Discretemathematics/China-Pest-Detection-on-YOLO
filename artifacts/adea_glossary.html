02 · 模型结构

模型长什么样

白话术语在本项目里具体指什么
把图缩小几倍后画出的一张"网格纸"feature map / stridestride=8 的网格纸，每个格子代表原图 8×8 像素。YOLO11n 有 8/16/32 三层；加了 P2 就是 4/8/16/32 四层
网格纸上的一个点anchor一个候选点。它自己不是框，只是个"位置"，会学着吐出框
这个点能不能负责这只虫in-box / mask_in_gts网格点落在虫的框内 → 有资格负责；落在框外 → 不负责
虫的框太小，框里装不下几个网格点stride_val 下限规则ultralytics 自带：边长小于 16px 的框会被"抬"到 16px，保证框里至少有点。这是 YOLOv7 式扩张的退化版
多加一层最细的网格纸P2 检测头stride=4 层，专治超小目标。复现 YOLO11-4K (arXiv:2512.16493)
换一种下采样，避免丢小目标信息SPD-Conv复现 arXiv:2202.01248
更好的注意力EMA 注意力复现 arXiv:2303.11366（EP-YOLO 论文里横向对比最优）
更好的上采样DySample复现 arXiv:2308.07096
骨干 / 脖子 / 头backbone / neck / headbackbone 提特征，neck 融合多层，head 出检测框。我们改的是 neck/head 的模块，不动 backbone 结构
03 · 标签分配（我们改的核心）

这一节是重点

白话术语在本项目里具体指什么
给虫分派"练习题"label assignment决定每个网格点负责学哪只虫。本项目创新所在层
被派到的练习题positive / 正样本这个网格点负责这只虫，就要算它的错
没被派到的negative / 背景要学"这里什么都没有"，防止乱报
每只虫最多几道题topkultralytics 默认给 10（实测每只虫最多 10 个正样本）。数字越小，题越少
这道题有多"划算"align_metric= 分类置信度0.5 × CIoU6。越大说明"这个点既能认对类别、又框得准"
两个框重叠多少IoU / CIoU交 ÷ 并（CIoU 还看中心距离和长宽比）
虫的框里能装下几个网格点候选池 candidate pool本项目新引入的度量。实测：最小档只有 0.41 个，最大档 88 个，差 200 倍
这只虫最多能拿到几道题（几何上限）min(topk, 候选池)纯几何量，与分辨率、模型结构无关 → 加了 P2 会自动变大
两个虫抢同一个网格点冲突 / contentionultralytics 的规则：只留给 IoU 最高的那个，另一个直接失去。实测这种情况只占 0.24%
给定大小，这只虫"本该"拿几道题期望份额 E[n_pos|a]按相对面积分档统计出来的平均值（6 档：2.27 / 4.07 / 6.31 / 9.84 / 9.99 / 10.0）
实际比期望少了多少残差 residual粘连目标残差 −0.761（被剥夺），孤立目标 0.000（正常）
题不够时把练习区域放大候选区扩展 / allowed areaM0。前人是 YOLOv7：给所有虫固定扩 5×5 网格；我们只给"题不够的"补，扩多少按 stride 算 本项目
抢到的题要还回去一些公平再分配 / 零和转移S2。总数不变，只是重新分；护栏 ρ=0.5 保证"至少一半匹配度"才肯让 本项目
从最饿的那个开始补max-min 公平 / min_gap优先补缺口最大的；转移后总缺口不变、最大缺口下降（实测 5.00 → 3.00）
高密度区域的配额调整DLA按密度场调制每个 GT 的最低题数 次要组件
按难度重新采样DRA动态采样器，专治稀有类 次要组件

怎么算分、怎么打分

白话术语

框歪了、偏了、小了回归损失 / DFL
每道题的罚分轻重weight
这道题算不算重要target score
报出来的框有多少是真的Precision
该找到的找到了多少Recall

从 50% 到 95% 十档严格标准平均mAP50-95

白话术语

分级抑制AGS
造一批"粘连样本"ASM 合成
把模型的取舍一个个拆开看消融 ablation
自己搭的强对照强基线 strong baseline
把别人论文的模块装进来复现 reproduction

SFW 用一句话说清：以前每道题权重一样，于是领 10 道题的大虫子在"总分"里的话语权 是领 1.8 道题的小虫子的 5.5 倍。SFW 改成"每只虫子的总贡献一样大"， 背景题权重不变、总权重守恒 → 损失量级不变，只是更公平。 前人 Balanced L1 Loss 处理的是回归项，我们处理的是分类项里"领几道题"这条通道。
05 · 常见误解

四个容易被误解的点

❌ "SLA 是全新发明的方法。"
更准确：名字与整体组装是本项目提的，但每个零件都有前人出处（YOLOv7 的 allowed area、ATSS/PAA 这一族、 Balanced L1 Loss）。增量在"诊断 + 份额的参数化"，不在原语。所以必须有 strong_SLA_fixed 这个 YOLOv7 式对照组。
❌ "正样本越多越好。"
不是。每个 GT 的正样本数被 topk=10 封顶；扩容只是让"几何上拿不到"的那些补上来， 大目标不受影响。本项目实测：微目标 1.80 → 2.96，大目标 9.87 → 9.94（几乎不变）。
❌ "粘连一定是坏事，越少越好。"
粘连子集的 mAP 确实更低（原论文：低 4.96 个点），但原因主要是特征与后处理， 不是分配层（实测"被邻居抢走"只占 0.24%）。所以粘连方向我们降级为 AGS 后处理 + ASM 合成， 创新主线转向尺度公平。
❌ "补丁打上了就等于生效了。"
这是这类工作最大的坑：训练照常跑、loss 正常下降，但补丁其实没起作用。 我们为此做了 assigner_health() 运行时自检（报错数 / 转移数 / 缺口）， 异常即判该次实验不可信。
